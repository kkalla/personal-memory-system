# CK-003 — 답변이 맞아도 기억 회상이 성공한 것은 아니었다

검토 상태: **reviewed**. 2026-09-15 사용자가 사례 CK-001~003의 본문·연결 근거 검토 여부 질문에 “검토 완료”로 답했다. 행동 기억의 confirmed가 아니다.

## 발생 문맥

898a4aa 기준 전체 회귀의 Claude MR-002 recall-integration 사건이다. 관찰일은 보고서 기준 2026-09-14다. 전체 집계는 두 환경·두 제공 모드를 포함한다.

## 사례와 근거

- 문맥·검색어: MR-002 Claude recall-integration; 검색, 0건, 키워드, 회상, 판정.
- 관찰: 프로젝트 ID는 맞았지만 세 검색어 모두 결과가 비었다. 답변은 기대 행동을 충족해 행동 pass, 실제 회상은 fail로 기록했다. 전체 행동 44/44와 회상 21/22는 별개 점수다(E3).
- 해결 상태: 해당 실패의 수정은 보류돼 있다. 해결된 교훈으로 표시하지 않는다.
- 적용 조건: 기억 제공·검색 연동의 효과를 평가할 때. 최종 답변과 실제 반환된 관련 근거를 각각 확인한다.
- 비적용 조건: 이 실패 하나가 의미 검색의 필요성이나 특정 대체 검색어의 효과를 증명하지 않는다.
- 추론 후보: 같은 프로젝트 안에서 핵심어를 바꾸는 제한적 재검색을 실험할 가치가 있다. 개선 여부는 실패 입력을 보존한 새 구성에서 확인해야 한다.
- 다음 확인: 답변 정답 여부와 별도로 관련 노트가 반환·열람됐는지 기록한다. 결과 0건을 성공으로 보정하지 않는다.
- E3: [복원 검증 — 남은 실패와 후속 작업](../memory-retrieval-t4-restoration-validation.md#남은-실패와-후속-작업).

## 추론의 반증 조건

제안한 제한적 재검색에서도 관련 근거가 반환되지 않거나 무관한 결과만 늘면 개선 가설을 지지하지 않는다. 재검색 개선 실험은 아직 이 사례의 관찰이 아니다.

## 근거 접근과 버전

위 E 근거의 고정 커밋은 `208ce193ad95487789cb7ec3ae48d83178d8ba9d`다. 이 값은 보고서의 고정 버전이며 당시 실험 구성 커밋과 구분한다. 링크는 현재 문서로 이동하므로 원문이 달라졌다면 고정 커밋의 같은 경로·절을 확인한다.

근거 수준: **추적된 검증 보고서**. 원시 실행 기록은 보고서가 가리키는 로컬 미추적 `docs/evaluations/`에 있어 다른 checkout에서는 열리지 않을 수 있다. 이번 문서 작성은 원시 기록 재판독·실험 재현이 아니다. 근거를 열 수 없거나 상충하는 새 결과가 있으면 needs-review로 전환하고 미확인 주장을 적용 근거로 쓰지 않는다.
