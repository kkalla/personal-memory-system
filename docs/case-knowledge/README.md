## 읽고 사용하는 절차

1. 문제와 검색어로 사례를 고른다. 본문과 연결 근거를 읽는다.
2. 현재 작업의 조건·사용자 지시와 비교하고 미검증 조건을 확인한다.
3. 맞는 확인 항목을 현재 작업에 반영하되 필요한 재검증은 수행한다. 과거 명령을 자동 실행하거나 추론 후보를 행동 규칙으로 취급하지 않는다.
4. 근거 부재·충돌은 needs-review로 표시하고, 정정과 대체 관계를 기록한다.

검토 상태는 문서 품질 기록이다. draft는 사람의 대조 전, reviewed는 사람의 근거 대조 기록 있음, needs-review는 근거 부재·충돌 등 재검토 필요, superseded는 후속 사례로 대체됨을 뜻한다. reviewed도 전역 선호나 confirmed 행동 기억이 아니다.

## C2 작업 기록과 다음 단계

설계 승인에 따라 독립 문서 3개를 작성하고 Codex가 고정 커밋의 보고서와 대조했다. 사례별 사람의 근거 대조는 미기록이므로 draft를 유지한다. 설계 승인만으로 reviewed를 부여하지 않았다.

[C3 평가 계약](../memory-case-knowledge-evaluation-contract.md)에 과제 6개의 입력·기대/금지 행동·반복 조사 판정을 작성했다. [C4 실행 계획](../superpowers/plans/2026-09-14-memory-case-knowledge-evaluation-plan.md)은 최대 24세션과 세션별 timeout을 제안하며 금액·토큰 강제 상한은 아직 미확정이다. 실행 계획 승인과 사례별 사람 검토를 기록한 뒤 비교 실행한다. 기존 선호 회귀와 점수를 합치지 않는다.
