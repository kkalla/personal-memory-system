## 읽고 사용하는 절차

1. 문제와 검색어로 사례를 고른다. 본문과 연결 근거를 읽는다.
2. 현재 작업의 조건·사용자 지시와 비교하고 미검증 조건을 확인한다.
3. 맞는 확인 항목을 현재 작업에 반영하되 필요한 재검증은 수행한다. 과거 명령을 자동 실행하거나 추론 후보를 행동 규칙으로 취급하지 않는다.
4. 근거 부재·충돌은 needs-review로 표시하고, 정정과 대체 관계를 기록한다.

검토 상태는 문서 품질 기록이다. draft는 사람의 대조 전, reviewed는 사람의 근거 대조 기록 있음, needs-review는 근거 부재·충돌 등 재검토 필요, superseded는 후속 사례로 대체됨을 뜻한다. reviewed도 전역 선호나 confirmed 행동 기억이 아니다.

## C2 작업 기록과 다음 단계

설계 승인에 따라 독립 문서 3개를 작성하고 Codex가 고정 커밋의 보고서와 대조했다. 2026-09-15 별도 검토 질문에 사용자가 “검토 완료”로 답해 세 사례를 reviewed로 기록했다. 검토 대상 본문은 커밋 8cb33a6이다.

[C3 평가 계약](../memory-case-knowledge-evaluation-contract.md)에 과제 6개의 입력·기대/금지 행동·반복 조사 판정을 작성했다. [C4 실행 계획](../superpowers/plans/2026-09-14-memory-case-knowledge-evaluation-plan.md)은 최대 24세션·세션당 600초·재시도 없음으로 진행한다. 2026-09-15 사용자 지시로 금액·토큰 강제 상한은 제외했으며 추가 승인 조건이 아니다. 사례별 사람 검토와 로컬 준비 검증을 마친 뒤 비교 실행을 완료했다. 기존 선호 회귀와 점수를 합치지 않는다.

[C4 첫 실행 기록](../memory-case-knowledge-c4-validation.md): Claude 임시 경로 오류로 1건 시작 실패·23건 미실행. 이는 첫 캠페인 당시 기록이며, 수정 구성의 최종 결과는 아래와 같다.

[C4 최종 결과](../memory-case-knowledge-c4-results.md): 새 24조건 시도 중 23개 완료·1개 시작 오류. 11쌍 중 개선 1·동률 10, 재조사 감소는 관찰되지 않았다. C5는 문서 운영 유지·자동화 보류를 권고한다.
