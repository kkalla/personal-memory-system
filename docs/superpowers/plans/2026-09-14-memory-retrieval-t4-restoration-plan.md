# T4 복원 안내 마무리 계획

기준 898a4aa. 사용자 “남은 작업 진행”에 따라 복원 코드 블록의 충돌 방지와 보류된 전체 회귀를 진행한다.

1. 공통 적용 지침에 실행 가능한 충돌 검사 + mkdir + mv -n 형식을 명시한다. 기존 주의 문구만으로 일반 mv를 보완하지 않는다. 제품 코드/API·fixture·핵심은 변경하지 않는다.
2. 기존 복원 검증기의 일반 mv 거부 및 mv -n/부모 생성 검증을 재사용한다. 단순 지침 문구를 반복하는 테스트는 만들지 않는다.
3. Claude MR-001/007/009 두 모드의 6세션·8턴을 집중 검증한다. 행동·회상 및 실제 복원 명령의 부재/충돌 검증이 모두 통과해야 전체 단계로 간다.
4. 같은 새 구성으로 기존 JSON 11개 × 두 환경 × 두 모드, 44세션·52턴을 실행한다. scope/status/후보/주제 전환 회귀와 보관 12건의 추가 충돌 보존을 확인한다.
5. 이번 새 실행 상한은 50세션·60사용자 턴이다. Claude sonnet-5/high, Codex gpt-6-astra/low, 기존 호출 시간/예산 제한을 유지한다. 각 구성은 한 번 실행하며 집중 실패·실행 장애 시 이후 단계는 미실행으로 남긴다.

원시 자료와 이전 실패를 보존한다. 실제 볼트·전역 설정·launchd·사용자 Stop hook·설치는 변경하지 않는다.

## 실행 결과

집중 6세션·8턴과 전체 44세션·52턴을 모두 완료했다. 집중 행동 6/6·연결 3/3, 전체 행동 44/44·연결 21/22다. 전체 복원 12개 명령은 부재/충돌 24조건을 모두 통과했다. Claude MR-002 검색 0건으로 인한 연결 실패는 유지하며 추가 모델 재시도 없이 종료했다. [최종 기록과 다음 수정 후보](../../memory-retrieval-t4-restoration-validation.md)를 참고한다.
